### Decisions made
- React Context over zustand for the open/close trigger — CLAUDE.md's stack list (§2) doesn't
  mention a client-state library, and `AuthContext` already established the pattern; adding
  zustand for one boolean would be a stack deviation not worth asking permission for. Rules out
  zustand unless a future screen needs cross-tree state Context genuinely can't handle well.
- Hand-wrote `components/ui/form.jsx` rather than skip shadcn Form primitives — the CLI's Nova
  preset just doesn't ship it, but the pattern (`FormField`/`FormItem`/`FormControl`/`FormMessage`
  wired to `react-hook-form`) is exactly what CLAUDE.md asks for pairing shadcn with
  react-hook-form, so it was worth reproducing rather than hand-rolling ad hoc form markup per
  step.
- Kept the ✦ glyph on the success screen instead of swapping it for a lucide icon — the task
  named that exact element, and it matches the ✦ brand mark already used unreplaced elsewhere
  (header, sidebar). CLAUDE.md's "replace emoji/glyph placeholders" rule is read as targeting
  functional icons (menu glyphs, meal emoji), not the wordmark itself.
